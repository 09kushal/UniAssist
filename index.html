✨ Architectural Highlights

Engineered for Reliability, Built for Students

Every module in UniAssist is crafted to replicate a professional peer-consultation lifecycle with bank-grade security.

💳

eSewa EPAY v2 Integration

Digital payments implemented via eSewa with client-to-server signature calculation, HMAC-SHA256 data signing, and instant backend payment status confirmation.

📹

8x8 JaaS HD Video Calling

WebRTC video meetings signed using RS256 private key tokens. Session rooms enforce strict join-time windows and auto-grant moderator rights to verified tutors.

🔔

Firebase Cloud Push Alerts

Real-time FCM notifications dispatch instantly when tutors accept/reject requests, when sessions start, and when payments complete.

🛡️

Lateness & Dispute Escalation

Students can report late or no-show tutors directly from their booking cards with automated dispute logging and instant WhatsApp administrator escalation.

⏱️

Self-Healing Booking Expiration

Background self-healing logic automatically sweeps past-scheduled unattended sessions and flags them as expired, keeping dashboards crisp and accurate.

🏛️

Django Admin Escrow Payouts

Admin portal features custom bulk-release actions allowing platform managers to verify completed sessions and release accumulated earnings to tutors.
